# 📊 Credit Default Analysis

## Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos em Ciência de Dados.

O objetivo foi realizar uma Análise Exploratória de Dados (EDA) utilizando Python para identificar padrões relacionados à inadimplência de clientes de cartão de crédito.

---

## Objetivos

- Entender o comportamento dos clientes
- Identificar fatores relacionados à inadimplência
- Produzir visualizações que auxiliem na tomada de decisão

---

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Etapas realizadas

- Limpeza dos dados
- Tratamento de valores ausentes
- Estatística descritiva
- Análise univariada
- Análise bivariada
- Visualização dos dados

---

## Principais insights

- Clientes inadimplentes apresentaram menor volume de transações.
- Houve associação entre maior período de inatividade e inadimplência.
- Clientes inadimplentes movimentam valores menores.
